# 桌面任务小组件

Windows桌面悬浮任务管理工具。

## 启动

双击 `DesktopTaskWidget.exe` 运行。首次启动会在同目录生成数据文件。

> Windows提示"已阻止不安全应用"：Windows安全中心 → 应用和浏览器控制 → 智能应用控制 → 关闭

## 界面

| 按钮 | 功能 |
|------|------|
| 📍 | 置顶/取消置顶 |
| ➕ | 添加任务（任务页）/ 添加习惯（习惯页） |
| 📋/🔄 | 切换任务页和习惯页 |
| ⚙ | 设置 |

## 任务管理

- **添加**：点 ➕，填写内容、截止时间、优先级，确定
- **完成**：点任务左侧圆圈
- **编辑/删除/归档**：双击任务

颜色含义：红色=紧急（1小时内到期），橙色=P1，蓝色=P2，白色=P3。完成的任务带删除线显示在底部。

## 习惯管理

切换到习惯页（📋/🔄按钮），点 ➕ 添加每日习惯，设置提醒时间。完成后点圆圈标记。

## 贴边隐藏

拖动窗口到屏幕左/右/上边缘，窗口自动隐藏。鼠标移到屏幕边缘触发区，窗口滑回。

## 饮水小助手

习惯页顶部显示。在 ⚙ 设置中启用，可设置杯量、提醒间隔、每日目标。点"喝一杯"/"喝半杯"/"抿一口"记录饮水，点 ▼ 查看今日记录。

## 设置（⚙）

- 窗口背景透明度、文字大小、文字透明度
- 开机自启动

## 数据文件

所有数据保存在exe同目录下：

| 文件 | 内容 |
|------|------|
| `tasks.json` | 任务数据 |
| `habits.json` | 习惯数据 |
| `water.json` | 饮水设置和记录 |
| `settings.json` | 窗口设置 |

备份：复制这4个文件即可。

## 系统要求

- Windows 10/11
- 开机自启动可能需要管理员权限
