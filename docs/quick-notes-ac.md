# 快速便签验收约定

- 主窗口增加独立便签切换按钮，保留任务与习惯功能。再次点击返回原页。
- Ctrl＋Alt＋N作为Windows全局快捷键；注册失败有提示，按钮入口可用；退出释放快捷键。
- 输入窗口Enter保存，Shift＋Enter换行，中文输入法组合文字期间不保存；空白拒绝保存。
- 保存成功关闭输入窗口并刷新便签列表，按创建顺序倒序，展示时间和正文；收起保留未保存草稿。
- 每条保存生成唯一id、带时区的created_at和content。数据库notes_archive.sqlite3保存便签与创建日志，同一事务提交。
- notes_log.jsonl提供每行一条的可读创建日志，原子替换；数据库是事实来源，日志可由数据库重建。
- 日志导出失败不影响已提交便签，不抛保存失败，NoteStore.log_error提供错误说明。重新加载重试导出。
- 数据库读取或写入失败明确报错，输入不丢失；重启后恢复历史便签。
- NoteStore(data_dir)，load_notes()返回倒序字典列表；create_note(content)返回新便签字典。
