# 快速便签验收约定

## 列表卡片与原位编辑

- 主窗口左上角不显示列表名称；待办事项和快捷便签合并为切换按钮，保留各自图标，置于新增按钮与饮水按钮之间；饮水按钮显示装水的水杯。
- 删除便签数量行，空态/错误提示继续显示。每条便签独立深色卡片，灰色小号创建时间在正文上方，卡片间留白分隔。
- 双击卡片直接进入编辑，绿色细边框、字符计数、取消和保存；不再打开查看对话框。
- Enter保存，Shift＋Enter换行，Esc取消；输入法选词不提交。空白不保存，失败保留草稿，取消恢复原文。
- 页面切换和定时刷新不得丢失编辑草稿；重回便签页恢复草稿。保存保留原id和创建时间，不改变原排序。
- NoteStore.update_note(note_id, content)原子更新正文并记录修改历史，返回{id, created_at, content}。原创建日志保留，修改日志包含修改时间与修改前后正文，可读日志重建同时包含创建与修改记录。旧数据库只读迁移至JSONL，原文件保留。

- 合并按钮在待办和便签之间切换；饮水页点击合并按钮返回最近使用的待办/便签列表。水杯按钮固定进入饮水页，重复点击保持当前页。
- Ctrl＋Alt＋N作为Windows全局快捷键；注册失败有提示，按钮入口可用；退出释放快捷键。
- 输入窗口Enter保存，Shift＋Enter换行，中文输入法组合文字期间不保存；空白拒绝保存。
- 保存成功关闭输入窗口并刷新便签列表，置顶优先、按展示时间倒序，展示时间和正文；收起保留未保存草稿。
- 每条保存生成唯一id、带时区的created_at和content。JSONL原子保存便签完整状态和操作事件。
- notes_log.jsonl是事件主文件；CSV为可重建的当前快照，不含归档便签。
- CSV导出失败不影响已提交便签，不抛保存失败，NoteStore.log_error提供错误说明。重新加载重试导出。
- JSONL读取或写入失败明确报错，输入不丢失；重启后恢复历史便签。
- NoteStore(data_dir)，load_notes()返回倒序字典列表；create_note(content)返回新便签字典。

## 2026-09-09弹窗调整

- 参考flomo截图改为白底无边框、左上中文标题、右上固定和收起图标、底部文字工具及发送按钮。
- 移除弹窗快捷键说明和列表中的双击查看说明，原快捷键和全文查看功能继续可用。
- 默认点击外部自动收起并保留草稿；固定后保持展开；点击内部控件或打开编辑区右键菜单不收起。
- 空内容发送按钮置灰，有内容显示绿色；存储成功才清空草稿，失败显示错误和数据目录。
- 底部工具为纯文本标签、无序/有序列表，不包含图片存储或富文本。
- 弹窗使用6px小圆角细边框，四边和四角均支持拖动缩放，最小尺寸320×300。
- 置顶图钉为绿色实心，不加选中底色；底部按钮变浅，悬停恢复颜色，操作不受影响。
