# 文件夹快速访问实现方案

状态：已按用户补充意见实现。取消固定显示开关，改用右键菜单排序。

## 界面与交互

- 仅待办事项页底部显示文件夹快速访问区，沿用透明背景与现有字体风格。
- 展开时约占内容区下半部分，优先保留该区域；上方待办列表缩小，超出部分滚动查看。
- 默认展开并保持展开，点击标题栏向下折叠；不提供固定显示开关。
- 向下折叠后只保留底部标题条，待办列表填充释放的空间，点击标题条恢复。
- 文件夹以图标在上、名称在下的网格显示，名称最多两行、超长省略，悬停显示完整路径。条目过多时区域内部滚动。正方形单元格在最小窗口宽度下每行3个。右键空白处按名称或修改日期排序，再次选择同一项反向排列，自动保存。
- 双击文件夹调用Windows默认方式打开目录。
- 空白区域右键新增文件夹，支持输入路径或浏览选择目录。
- 条目右键修改路径或删除快捷入口，删除不影响实际文件夹。
- 路径无效时提示；新增或修改取消时不改变数据；避免重复添加相同路径。
- 自动保存路径列表、排列顺序与折叠状态，重启恢复。
